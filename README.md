# GhostCache

## Description
GhostCache is a platform for anonymous end-to-end encrypted chat and self-destructing secure file sharing. Designed with privacy and security in mind, it allows users to communicate and share sensitive information without fear of exposure.

## Features
- **Anonymous Chat**: Engage in secure conversations without revealing your identity.
- **End-to-End Encryption**: All messages and files are encrypted, ensuring that only designated recipients can access them.
- **Self-Destructing Files**: Share files that automatically delete after a specified period or once they have been accessed.
- **User-Friendly Interface**: A simple and intuitive interface for seamless interaction.
